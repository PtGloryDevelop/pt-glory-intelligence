# PT Glory AI Change

Use for prompt, model, taxonomy, classifier, Deep Search synthesis, or AI output-contract changes.

## Workflow

1. Define what AI is responsible for vs deterministic code.
2. Select stable evaluation/golden dataset.
3. Define expected outputs and evidence requirements.
4. Implement prompt/model/output change.
5. Run evaluation.
6. Verify evidence references.
7. Calculate deterministic counts/percentages outside model prose.
8. Measure token/cost impact.
9. Compare to current production baseline.
10. Version prompt/model config.

Do not deploy because a single sample looks good.

Do not allow the model to invent unsupported performance facts.
