# หน้าแรกที่เริ่มส่องแอดได้ — 3 ตุลาคม 2569

ผู้ใช้ให้ทำส่วนอื่นระหว่างรอสิทธิ์เพจ Facebook และก่อนหน้านี้แจ้งว่าหน้าแรกมีแต่รูปแอดเรา จึงไม่เห็นว่าจะส่องคู่แข่งอย่างไร รอบนี้แก้ทางเข้าและลำดับงานโดยใช้ข้อมูลและสีหน้าจอที่มีอยู่ ไม่เพิ่มแหล่งข้อมูลหรือเริ่มเก็บข้อมูลอัตโนมัติ

## เส้นทางที่ใช้

- `/`: ช่องค้นสินค้า/เพจส่งไปคลังคู่แข่ง พร้อมทางลัดแอดที่เพิ่งพบ เพจ และรายการติดตาม
- ภาพรวมแสดงผลแอดเราตามวันที่ของ snapshot จริง แยกสกุลเงินและ ROAS แบบถ่วงน้ำหนัก คู่แข่งแสดงสถานะที่เก็บไว้และวันที่เก็บล่าสุด
- คู่แข่งแสดงสองตัวอย่างพร้อมข้อความและปุ่มเทียบ เก็บ dataset กับ ad archive ID ของหลักฐานเดิม
- แอดเราแสดงสามรายการค่าแอดสูง พร้อมผลลัพธ์และปุ่มเปิดสื่อ โหลดสื่อเพิ่มเติมเมื่อเปิดรายละเอียดเท่านั้น ค่าแอดสูงไม่ใช่คำตัดสินว่าแอดไม่ดี
- `/owned-ads/performance`: หน้าคลังผลลัพธ์รายวันเดิม พร้อมตัวกรองและการดูวิดีโอ
- `/command-center`: การจัดอันดับเดิม `/owned-ads`: คลังทุกแอดและการอัปเดตข้อมูลเดิม

การเทียบจากภาพรวมใช้ผลรอบนำเข้า ไม่ถูกเปลี่ยนเป็นค่าเริ่มต้น 7 วัน การเทียบจากผลรายวันรักษาช่วงวันที่และตัวกรอง การกลับหน้าต้นทางรักษาคำค้นและหน้าเดิม ลิงก์เก่า `/?period=...` ส่งไปหน้าผลรายวันพร้อม query ทุกค่า รวมค่าซ้ำให้ตัวตรวจเดิมตัดสินความถูกต้อง

## ขอบเขตข้อมูลและสิทธิ์

ไม่แก้ฐานข้อมูลต้นทาง ไม่เปลี่ยนสิทธิ์ Facebook ไม่รัน Apify หรือซิงก์อัตโนมัติจากการเปิดหน้าแรก การค้นในคลังใช้ข้อมูลที่บันทึกไว้ ส่วน viewer เห็นงานวิจัยคู่แข่งและรายการติดตามโดยไม่มีข้อมูลการเงินหรือหน้าผลแอดเรา

“เพิ่งพบ” หมายถึงวันที่ระบบพบครั้งแรก ไม่ใช่วันที่เริ่มยิง ไม่มีข้อมูลกำไรจริง %ปิดจากระบบขาย หรือคำแนะนำ AI ที่สร้างขึ้นใหม่
