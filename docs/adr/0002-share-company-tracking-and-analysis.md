# รายการติดตามหลักและบทวิเคราะห์เป็นข้อมูลร่วมบริษัท

รายการเป้าหมายที่ใช้เก็บรายวันและบทวิเคราะห์สำหรับทีมการตลาดกับเจ้าของบริษัทเป็นข้อมูลร่วมกันตามคำตอบ Q13 เพื่อให้ตัดสินใจจากข้อมูลชุดเดียวกัน ขอบเขตนี้แยกจาก Watchlist ส่วนตัวที่มีอยู่ ซึ่งสิทธิ์เป็นของผู้สร้างและไม่เหมาะเป็นรายการเก็บข้อมูลหลักของบริษัท
