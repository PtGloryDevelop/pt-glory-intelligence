# ใช้เนื้อหาแอดทุกประเภทเป็นข้อมูลวิเคราะห์

การวิเคราะห์แอดสุขภาพและความงามจาก Meta ในประเทศไทยต้องครอบคลุมข้อความแอด ข้อความบนภาพ คำพูดและข้อความบนจอในวิดีโอ พร้อมหลักฐานที่เปิดตรวจได้ ตามคำตอบรอบสองของผู้ใช้ เลือกขอบเขตนี้แทนการอ่านเฉพาะข้อความแอดและเก็บภาพตัวอย่างหนึ่งภาพ เพราะข้อเสนอที่ต้องใช้ตัดสินใจอาจปรากฏในส่วนอื่นของสื่อ การตัดสินใจนี้เพิ่มภาระการรับและวิเคราะห์สื่อ ซึ่งต้องทำทันขณะที่ยังเข้าถึงต้นทางได้

คำตอบรอบสามกำหนดให้เก็บไฟล์ภาพ/วิดีโอ 12 เดือน ส่วนข้อมูลแอด ข้อความที่อ่านหรือถอดได้ และผลวิเคราะห์เก็บระยะยาว จึงต้องแสดงให้ชัดเมื่อไฟล์สื่อต้นฉบับพ้นระยะเก็บและเหลือเฉพาะข้อความ/ผลวิเคราะห์ที่บันทึกไว้
