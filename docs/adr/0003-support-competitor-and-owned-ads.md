# เว็บเดียวรองรับทั้งแอดคู่แข่งและแอดบริษัท

ผู้ใช้ยืนยันให้ PT Glory รองรับทั้งการส่องแอดคู่แข่งและข้อมูลแอดของบริษัทในเว็บเดียวกัน จึงขยายจากขอบเขตเดิมที่มีเฉพาะข้อมูล Ad Library โดยรักษาที่มา ความหมายของตัวเลข และสิทธิ์ของข้อมูลแต่ละส่วนให้ชัดเจน ผลงานแอดบริษัทแสดงได้เมื่อมีแหล่งจริงที่ได้รับสิทธิ์ แต่ข้อมูลสาธารณะคู่แข่งยังไม่ใช่หลักฐานยอดขายหรือ ROAS ของคู่แข่ง และการรองรับทั้งสองส่วนไม่ใช่เหตุให้ยกเลิกการตรวจข้อมูลสาธารณะเดิม
